# POE装备自动洗练工具

基于剪贴板分析的Path of Exile装备自动洗练工具，用于自动化筛选符合特定条件的装备词缀。

## 功能特性

- ✅ 基于剪贴板分析装备属性，无需OCR图形识别
- ✅ 多标签界面设计，操作直观便捷
- ✅ 支持设置包含/排除词条条件，精准匹配洗练目标
- ✅ 支持多装备位置管理，可快速切换不同装备
- ✅ 支持多通货位置管理，可自定义通货类型
- ✅ 详细的操作日志记录，便于追踪洗练结果
- ✅ 快捷键支持，提高操作效率
- ✅ 配置自动保存，重启程序后保持设置
- ✅ 模块化设计，代码结构清晰，易于维护和扩展

## 系统要求

- Windows 7/8/10/11 操作系统
- Python 3.8 或更高版本
- 必要的Python依赖包

## 安装方法

### 1. 安装Python

如果您的系统尚未安装Python，请先下载并安装：

1. 访问 [Python官网](https://www.python.org/downloads/)
2. 下载最新的Python 3.x版本并安装
3. 安装时确保勾选 "Add Python to PATH"

### 2. 安装依赖包

打开命令提示符(cmd)或PowerShell，导航到项目文件夹，执行以下命令：

```bash
pip install -r requirements.txt
```

### 3. 运行程序

直接双击 `auto_washer_gui.py` 文件，或在命令行中执行：

```bash
python auto_washer_gui.py
```

## 使用说明

### 1. 基本流程

1. **设置目标词条**：在"目标词条"标签页中添加您想要匹配的词条
2. **记录位置**：使用F11记录装备位置，使用F12记录通货位置
3. **开始洗练**：点击"开始洗练"按钮或按F10启动自动洗练
4. **监控进度**：在"操作日志"标签页中查看洗练进度和结果

### 2. 目标词条设置

在"目标词条"标签页中，您可以：

- **添加包含词条**：点击"添加包含词条"按钮，输入您希望装备包含的词条
- **添加排除词条**：点击"添加排除词条"按钮，输入您不希望装备包含的词条
- **移除词条**：选中要移除的词条，点击"移除选中词条"按钮
- **清空词条**：点击"清空所有词条"按钮，删除所有词条设置
- **匹配模式**：选择"AND"（需要匹配所有包含词条）或"OR"（只需匹配任一包含词条）

### 3. 装备管理

在"装备管理"标签页中，您可以：

- **记录当前位置**：点击"记录当前位置"按钮，输入装备名称，记录鼠标当前位置
- **快速记录**：按F11快捷键，使用默认名称（装备1、装备2...）快速记录
- **切换装备**：从列表中选择装备，点击"切换装备"按钮，切换当前使用的装备
- **移除装备**：选中要移除的装备，点击"移除选中装备"按钮
- **清空装备**：点击"清空所有装备"按钮，删除所有记录的装备位置

### 4. 通货管理

在"通货管理"标签页中，您可以：

- **记录当前位置**：点击"记录当前位置"按钮，输入通货名称，记录鼠标当前位置
- **快速记录**：按F12快捷键，使用默认名称（通货1、通货2...）快速记录
- **切换通货**：从列表中选择通货，点击"切换通货"按钮，切换当前使用的通货
- **移除通货**：选中要移除的通货，点击"移除选中通货"按钮
- **清空通货**：点击"清空所有通货"按钮，删除所有记录的通货位置

### 5. 主界面操作

- **开始/停止洗练**：点击"开始洗练"按钮或按F10快捷键
- **暂停/继续**：点击"暂停/继续"按钮，暂时停止或继续洗练过程
- **状态显示**：显示当前运行状态、已用时间和尝试次数

### 6. 日志查看

在"操作日志"标签页中，您可以：

- **查看操作记录**：显示所有操作和匹配结果
- **匹配结果详情**：显示每次尝试的匹配状态、匹配到的词条和未匹配的词条
- **清空日志**：点击"清空日志"按钮，清除当前显示的日志内容

## 快捷键列表

|--------|--------|
| F10    | 开始/停止自动洗练 |
| F11    | 快速记录装备位置 |
| F12    | 快速记录通货位置 |

## 工作原理

1. **装备属性获取**：程序使用键盘快捷键Ctrl+C复制鼠标悬停的装备信息
2. **文本分析**：分析剪贴板中的装备文本，提取属性和词缀信息
3. **词缀匹配**：根据用户设置的条件，检查装备是否符合洗练目标
4. **自动操作**：根据匹配结果，自动进行拾取、使用通货、检查结果等操作

## 注意事项

1. **游戏兼容性**：请确保游戏处于窗口化或全屏窗口化模式，以便程序可以正确捕获鼠标位置和执行操作
2. **装备复制**：程序依赖游戏的Ctrl+C复制功能，请确保此功能正常工作
3. **安全使用**：请合理使用自动工具，遵守游戏规则，避免可能的账号风险
4. **鼠标位置**：记录装备和通货位置时，请确保鼠标准确悬停在目标上
5. **程序焦点**：执行自动洗练时，游戏窗口需要保持焦点

## 配置文件

程序配置保存在`config.ini`文件中，包含以下主要配置项：

- **General**：基本设置，如调试模式、剪贴板检查延迟等
- **ConditionalTargets**：目标词条设置
- **EquipmentPositions**：记录的装备位置
- **CurrencyPositions**：记录的通货位置

## 错误处理

如果程序出现错误，请查看以下位置获取帮助：

1. **日志文件**：程序会在`logs`目录下生成详细的日志文件
2. **错误对话框**：发生严重错误时，会显示错误信息对话框
3. **控制台输出**：如果从命令行运行，错误信息会输出到控制台

## 常见问题

### Q: 程序无法复制装备信息怎么办？
A: 请确保：
- 游戏中鼠标确实悬停在装备上
- 使用的是游戏支持的语言
- Ctrl+C复制功能在游戏中正常工作

### Q: 程序无法点击正确的位置怎么办？
A: 
- 重新记录装备和通货位置
- 确保游戏窗口大小和位置未改变
- 检查游戏是否处于全屏窗口化或窗口化模式

### Q: 洗练过程中程序卡住了怎么办？
A: 
- 按F10停止洗练
- 检查游戏窗口是否有焦点
- 检查日志文件了解可能的错误原因
